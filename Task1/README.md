# Безопасность данных

[Mindmap в draw.io](data-security.drawio) · [SVG](data-security.svg).

Данные разделены на четыре категории. Для каждой указаны пять рисков, оценка и причина.

| Оценка | Что означает |
| --- | --- |
| Незначительный | Небольшой локальный ущерб; работа с клиентами почти не затронута |
| Значительный | Ошибка бизнес-процесса, простой или заметные затраты на восстановление |
| Критический | Массовое раскрытие ПДн, чужой доступ, нарушение сделок, расчётов или физической безопасности |

За основу взяты [ISO/IEC 27001](https://www.iso.org/standard/27001) и [ISO/IEC 27002:2022](https://www.iso.org/standard/75652.html). Названия категорий заданы в работе, сам стандарт не требует именно такого списка. «Секретные» — внутренний класс данных, не государственная тайна. Биометрия и номера автомобилей пока планируются.
